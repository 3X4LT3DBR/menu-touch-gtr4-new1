# Menu Touch — Amazfit GTR 4 New

Projeto experimental para criar um menu acessível por toque no Amazfit GTR 4 New (480×480), reduzindo a dependência do botão superior/coroa.

## Objetivo
Expor atalhos para as funções do relógio por uma interface touch e, quando suportado pelo firmware/API, tentar abrir aplicativos nativos.

> Observação: a abertura direta de apps nativos depende das APIs realmente disponíveis no firmware do relógio. Rotas legadas precisam ser testadas no dispositivo.
